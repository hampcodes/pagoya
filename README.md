Plataforma web de pagos simple: permite iniciar sesión, administrar cuentas,
hacer transferencias y revisar reportes desde un solo lugar. Es un proyecto
estático (HTML, CSS y JavaScript puro) que guarda la información en el navegador
con `localStorage`.

## Funcionalidades

- **Registro e inicio de sesión** de usuarios con validación de datos.
- **Cuentas:** crear, editar, eliminar y buscar cuentas bancarias.
- **Transferencias:** registrar y listar movimientos entre cuentas.
- **Reportes:** resumen de ingresos, egresos y movimientos por categoría.
- **Perfil:** actualizar datos personales y cambiar la contraseña.
- **Diseño responsive:** se adapta a computadora, tablet y celular.

## Tecnologías

- HTML5
- CSS3
- JavaScript (ES Modules)
- localStorage

## Cómo usar

1. Descarga o clona el proyecto.
2. Abre `index.html` en tu navegador.

> No necesita instalación ni servidor: es un sitio estático.
